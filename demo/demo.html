Code overview
routing/views.py → POST/GET /api/v1/route/
routing/services.py → geocode start/finish → 1× OSRM route → fuel plan → JSON
routing/clients.py → free Nominatim + OSRM (cached)
routing/optimizer.py → greedy cost-optimal fills (500 mi / 10 MPG)
stations/models.py → FuelStop from assessment CSV
stations/.../import_fuel_prices.py → offline city lat/lng join (fast, no live geocode per station)
